  3. Other free ways to run the cron jobs

  - (b) Render's free server sleeps.

  - How: already set up.
  - ✅ Free, real logs, a red ❌ on failure, no Render dependence, nothing extra
    to keep running.
  - ❌ Runs start 5–20 minutes late, and the schedule pauses after 60 days
    without a commit. Yahoo or NSE might block GitHub's servers too, but you'll
    see it in the log.

  B. cron-job.org (a free external timer that calls your Render API)
  - How: sign up, add a job with the URL
    https://enam-finn.onrender.com/api/jobs/<name>, method POST, and header
    Authorization: Bearer <JOB_TOKEN>, then pick a schedule.
  - ✅ Exact timing (down to the minute) and simple. It's also handy for pinging
    /api/health every 14 minutes so Render never sleeps and the app opens
    instantly.
  - ❌ The job still runs on Render, so it has the same Yahoo blocking and
    hidden background-job problem you just hit. Use it only for jobs that don't
    fetch anything, like build_digest and tripwires, or for keep-awake pings.

  C. Your laptop with Windows Task Scheduler
  - How: a scheduled task runs python -m app.jobs.cli job eod_prices with
    DATABASE_URL set.
  - ✅ Home internet, which Yahoo and NSE almost never block, so it's the most
    reliable data source.
  - ❌ Only runs while the laptop is on and awake. Your laptop's security policy

    driver as a fallback first.

  D. Cloudflare Workers Cron Triggers
  - How: a tiny JavaScript worker with a cron schedule that calls your Render

  - ✅ Free, exact timing, very reliable.
  - ❌ Can only call a URL, not run your Python, so it has the same Render and

  E. A timer inside the backend (e.g. APScheduler on Render)
  - ✅ No outside service needed.
  - ❌ It doesn't fire while Render's free server is asleep, and the Yahoo
